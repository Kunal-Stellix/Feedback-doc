Users can submit ideas through the public portal or any embedded widget placed on your product.

## Submission flow

<Steps>
  <Step title="Open the submission form">
    User clicks **Submit Idea** on the portal or an embedded widget.
  </Step>
  <Step title="Real-time duplicate check">
    As the user types, the system surfaces similar existing ideas — advisory only, not blocking. The user can still proceed even if a match appears.
  </Step>
  <Step title="Add details and submit">
    User selects a category, optionally adds tags, and clicks **Submit**.
  </Step>
  <Step title="Moderation routing">
    - If moderation is set to `auto-approve` → the idea goes live immediately.
    - If moderation is set to `require-review` → the idea enters the pending queue for admin review.
  </Step>
  <Step title="Confirmation">
    Submitter receives a confirmation email and is automatically followed on their own idea so they receive all future status notifications.
  </Step>
</Steps>

## Moderation modes

| Mode | Behaviour |
|---|---|
| `auto-approve` | Idea is immediately public and voteable |
| `require-review` | Idea enters `Pending` queue; admin must approve before it goes live |

<Warning>
  In `auto-approve` mode, spam and low-quality ideas can surface immediately. Consider enabling keyword filters or restricting submissions to authenticated users.
</Warning>
