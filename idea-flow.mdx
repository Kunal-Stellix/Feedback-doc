## Primary status progression

```
Pending → Under Review → Planned → In Progress → Shipped
```

<Note>
  From any status, an idea can also transition to **Declined**, **Archived**, or **Merged**.
</Note>

## Status pills reference

| Status | Description |
|---|---|
| `Pending` | Submitted; awaiting admin review |
| `Under Review` | Team is actively evaluating the idea |
| `Planned` | Officially added to the roadmap |
| `In Progress` | Being actively built |
| `Shipped` | Feature is live for users |

## Exit statuses

Any idea at any stage can exit the primary flow via:

- **Declined** — the team will not build it; reason is shown publicly
- **Archived** — hidden from public view, preserved internally
- **Merged** — absorbed into another idea; submitter and voters are redirected
